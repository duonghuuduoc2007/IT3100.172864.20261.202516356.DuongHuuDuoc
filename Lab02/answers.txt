Exercise 4.1
1. Khi bấm nút Cancel chương trình trả về "You've chosen: No".
2. Để chỉ có hai lựa chọn Yes/No ta sửa:
		int option = JOptionPane.showConfirmDialog(null,
			"Do you want to change the first class ticket?");
thành:
		int option = JOptionPane.showConfirmDialog(null,
			"Do you want to change the first class ticket?",
			"Option", JOptionPane.YES_NO_OPTION);
Để chỉ có hai lựa chọn I do/I don't ta sửa lại thành:
	import javax.swing.JOptionPane;
	public class ChoosingOption {
		public static void main(String[] args) {
			String[] options = {"I do", "I don't"};
			int option = JOptionPane.showOptionDialog(null,
					"Do you want to change the first class ticket?",
					"Option", JOptionPane.DEFAULT_OPTION, JOptionPane.QUESTION_MESSAGE,
					null, options, options[0]);
			
			JOptionPane.showMessageDialog(null, "You've chosen: "
						+ (option==JOptionPane.YES_OPTION?"I do":"I don't"));
			System.exit(0);
		}
	}
